# Soft Ice - Safeguard Pro
Health, Safety & Security Operations for Soft Ice Catering Equipment.

## Host on GitHub Pages
1. Create repo e.g. soft-ice-safeguard
2. Upload ALL files in this folder to repo root
3. Settings > Pages > Deploy from branch > main > / (root) > Save
4. URL: https://YOUR-USERNAME.github.io/soft-ice-safeguard/
5. Phone: Chrome/Edge > Add to Home Screen / Install App

## Features in this version
- 4 sites: Soft Ice Catering Main, Unit 13, Unit 10, Unit 21
- Departments only for Soft Ice Main, Warehouse Area for warehouses
- Audits + Editable Audit Templates per Site + Auto Corrective Actions
- Reminders & Due Calendar, Monthly Compliance Report
- Photo Evidence (camera/file, no link field), Risk Assessment Library
- Inspection Schedule for Assets, First Aid & Stock
- Incidents, Corrective Actions, Assets + Borrowing Form, Hazards, SOP Library, Site Plans
- Notes on every record, Offline banner, Download Document on every record
