# Soft Ice - Safeguard Pro
Health, Safety & Security Operations for Soft Ice Catering Equipment.

## Host on GitHub Pages (free)
1. Create a new repo on GitHub, e.g. `soft-ice-safeguard`
2. Upload ALL files in this folder to the repo root (index.html, manifest.json, sw.js, .nojekyll)
3. Optional: add icon-192.png and icon-512.png - use your Soft Ice logo (square, blue background)
4. GitHub > Repo > Settings > Pages > Source: Deploy from a branch > Branch: main > Folder: / (root) > Save
5. Wait 1-2 min. Your URL: https://YOUR-USERNAME.github.io/soft-ice-safeguard/
6. Open that URL on phone > Chrome/Edge menu > Add to Home Screen / Install App

## Files
- index.html - the full app (single file, all data saves in the app database / browser)
- manifest.json - PWA install info
- sw.js - offline service worker
- .nojekyll - tells GitHub Pages to serve files as-is
- icon-192.png / icon-512.png - NOT included, add your logo files with these exact names
