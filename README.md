# Soft Ice — Safeguard Pro

Health & Safety Operations app. **Only ONE html file: `index.html`.**

Other files are not pages:
- `manifest.webmanifest` — lets phones install it as an app
- `sw.js` — offline support
- `.nojekyll` — tells GitHub Pages to serve files as-is
- `README.md` — this file

## Put it on GitHub Pages
1. Create a new repo, upload this whole folder.
2. Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
3. Open the Pages link.

## Use
- Data saves in the browser (localStorage). Use Backup & Restore → Download Backup regularly.
- Search at the top searches every register.
- Action Tracker is a Kanban board — change status with the dropdown on each card.
- Print / PDF prints the current view.
- Export CSV is on Audits, Incidents, Actions, Hazards and Assets.
